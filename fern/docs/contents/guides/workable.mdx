#### Obtaining a Workable API token

-   Open a [Workable account](https://www.workable.com/).
-   As a Super Admin, go to Settings > Integrations > API and generate an API access token. Enable the `r_jobs` and `r_candidates` scopes on the token.
-   Note your Workable account subdomain: it is the part before `.workable.com` in your Workable URL (for example, `acme` in `https://acme.workable.com`). You will need it when connecting.

#### Connect to Workable via Revert

-   Create an account on Revert if you don't already have one. (https://app.revert.dev/sign-up)
-   Login to your revert dashboard (https://app.revert.dev/sign-in) and click on `Create App` - `Workable`
-   Enter your Workable API token and your account subdomain when prompted.
