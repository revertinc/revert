#### Obtaining Workable API Access Token and Subdomain

-   Log into your [Workable account](https://www.workable.com).
-   Open the top-right menu and navigate to **Settings -> Integrations -> Access Token**.
-   Generate a new API access token with the required scopes (`r_jobs`, `r_candidates`, `w_candidates`).
-   Find your account subdomain in your company profile settings (e.g., `acme` from `https://acme.workable.com`).

#### Connect to Workable via Revert

-   Create an account on Revert if you don't already have one (https://app.revert.dev/sign-up).
-   Log into your Revert dashboard and click on **Integrations -> Workable**.
-   Enter your Workable account subdomain in the credentials configuration and connect using your API access token or OAuth app credentials.
